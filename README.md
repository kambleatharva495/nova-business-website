# Nova Business Website 🚀

A modern and responsive business website built using HTML, CSS and JavaScript.

## 🌐 Project Overview

Nova is a clean and modern business website designed to showcase services, projects and business information.

The website focuses on responsive design, simple navigation and interactive user experience.

## ✨ Features

- Responsive design for desktop, tablet and mobile
- Modern navigation bar
- Hero section with call-to-action
- About section
- Services section
- Portfolio section
- Project details page
- Contact section
- Smooth scrolling
- Interactive buttons and hover effects
- Mobile-friendly navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
